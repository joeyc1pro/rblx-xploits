## 🚀 Scripts

### Rivals ESP
**File:** `RivalsESP.lua`

A fully-featured ESP (Extra Sensory Perception) script with a sleek, modern UI.

**Features:**
- 📦 **Bounding Boxes** - Wireframe boxes around players
- 👤 **Player Names** - Display names with outline
- ❤️ **Health Bars** - Color-coded health indicators
- 📏 **Distance Display** - Shows distance in studs
- 🎯 **Tracers** - Lines from screen center to players
- ✨ **Highlight/Chams** - See players through walls
- 🎨 **Customizable UI** - Toggle individual features
- ⌨️ **Keybind Support** - RightShift to show/hide panel
- 📊 **Player Counter** - Live player count display

**Controls:**
- `RightShift` - Toggle UI visibility
- Click status bar - Enable/disable ESP
- Individual toggles for each feature

## 💾 Installation

### Method 1: Direct Copy/Paste
1. Open your preferred Roblox executor
2. Copy the script content from the desired `.lua` file
3. Paste into the executor
4. Click "Execute" or "Inject"

### Method 2: Loadstring (Recommended)
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPO/main/RivalsESP.lua"))()
```

### Method 3: Download & Load
1. Download the `.lua` file
2. Load it using your executor's "Load Script" function
3. Execute the script

## 🔧 Compatibility

### Supported Executors
- ✅ Synapse X
- ✅ Script-Ware
- ✅ KRNL
- ✅ Fluxus
- ✅ Electron
- ✅ Most modern executors with Drawing API support

### Requirements
- **Drawing API** - Required for ESP features
- **Instance.new("Highlight")** - Required for Chams
- **UserInputService** - Required for keybinds
- **CoreGui access** - Required for UI rendering

### Known Issues
- Some executors may not support all Drawing API features
- Highlights may not work on older executors
- Performance may vary based on player count
